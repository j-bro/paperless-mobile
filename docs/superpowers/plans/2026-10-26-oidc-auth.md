# OIDC Auth Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add OIDC SSO login with dual flows: prefer direct-to-IdP (system browser + PKCE + allauth headless) when the server supports it, else fall back to WebView server-login + `generate_auth_token` session exchange. Password/API-key login unchanged.

**Architecture:** Capability detection after server-URL entry classifies each server as `direct` (headless JSON reachable + provider client data found), `webFallback` (login page lists OIDC providers), or `none`. Direct reuses the existing `OidcCubit`/AppAuth path; fallback opens a WebView on the server login, completes SSO there, then JS-`fetch`es `POST /api/profile/generate_auth_token/` with the session cookie to obtain the existing DRF `Token`. Both converge on `AuthenticationCubit.addUser()` unchanged.

**Tech Stack:** Flutter/Dart, `flutter_appauth: ^7.0.0`, `webview_flutter: ^4.2.1` (already present), `dio: ^5.9.0`, `flutter_bloc: ^9.1.1`, `go_router: ^16.2.4`, `flutter_secure_storage` via existing `EncryptedLocalStore`.

## Global Constraints

- Minimum server for DIRECT flow: paperless-ngx v3.x with PR #11756 allauth headless. WEB-FALLBACK flow works on v2.x+ (verified pattern on v2.17.1: login page + `generate_auth_token`). Servers with neither show old UI unchanged.
- Public OIDC client only for DIRECT flow: PKCE S256, no client secret bundled in app.
- System browser only for DIRECT flow via `flutter_appauth` (Custom Tabs / ASWebAuthenticationSession). Embedded `webview_flutter` is permitted ONLY for the WEB-FALLBACK server-login flow (user's own server + its IdP, no credential exfiltration, token passed via JS bridge only, never logged).
- Custom scheme `paperlessmobile://oidc-callback` registered on Android + iOS (direct flow); IdP must also whitelist `https://<server>/accounts/oidc/<provider>/login/callback/`.
- Downstream unchanged: final credential is still DRF `Authorization: Token <token>` in `SessionManagerImpl.updateSettings()`; `UserCredentials.token` format unchanged.
- Secret-required IdPs (Google/MS/GitHub with secret) are out of scope v1 — show documented fallback to manual API-key.
- No custom server endpoints (`/api/auth/external-login/*` rejected upstream — do not implement).
- Redact tokens/user-ids in logs via existing `redactUserId` / logger utils; never log `code_verifier`, `code`, tokens.

```dart
// lib/api/modules/oidc_api.dart
import 'package:dio/dio.dart';
import 'package:paperless_mobile/features/login/oidc/model/oidc_provider.dart';

class OidcApi {
  final Dio _dio;
  OidcApi(this._dio);

  Future<List<OidcProvider>> fetchProviders(String serverUrl) async {
    try {
      final res = await _dio.get(
        '$serverUrl/api/profile/social_account_providers/',
        options: Options(validateStatus: (s) => s != null && s < 500),
      );
      if (res.statusCode == 404) return [];
      final data = res.data;
      final list = data is List ? data : (data is Map ? (data['results'] ?? data['providers'] ?? []) : []);
      if (list is! List) return [];
      return list.whereType<Map>().map((e) => OidcProvider.fromJson(Map<String, dynamic>.from(e))).toList();
    } on DioException {
      return [];
    }
  }
}
```

```dart
// append to lib/api/modules/oidc_api.dart
class OidcSessionExpired implements Exception {}
class OidcSignupRequired implements Exception {
  final String? sessionToken;
  OidcSignupRequired(this.sessionToken);
}

class OidcExchangeResult {
  final String? sessionToken;
  final String? accessToken;
  final bool mfaRequired;
  const OidcExchangeResult({this.sessionToken, this.accessToken, this.mfaRequired = false});
}

extension OidcHeadlessApi on OidcApi {
  Map<String, String> _headers(String? sessionToken) =>
      sessionToken == null ? {} : {'X-Session-Token': sessionToken};

  OidcExchangeResult _parse(dynamic data) {
    final meta = (data is Map ? data['meta'] : null) as Map? ?? {};
    final flows = (data is Map ? (data['data'] as Map?)?['flows'] : null) as List? ?? [];
    final hasMfa = flows.any((f) => (f as Map)['id'] == 'mfa_authenticate');
    final hasSignup = flows.any((f) => (f as Map)['id'] == 'provider_signup');
    if (hasSignup) throw OidcSignupRequired(meta['session_token'] as String?);
    return OidcExchangeResult(
      sessionToken: meta['session_token'] as String?,
      accessToken: meta['access_token'] as String?,
      mfaRequired: hasMfa,
    );
  }

  Future<OidcExchangeResult> exchangeProviderToken({
    required String providerId,
    required String idToken,
    String? accessToken,
    String? sessionToken,
  }) async {
    final res = await _dio.post(
      '/_allauth/app/v1/auth/provider/token',
      data: {'provider': providerId, 'token': {'id_token': idToken, if (accessToken != null) 'access_token': accessToken}},
      options: Options(headers: _headers(sessionToken), validateStatus: (s) => s != null && s < 500),
    );
    if (res.statusCode == 410) throw OidcSessionExpired();
    return _parse(res.data);
  }

  Future<OidcExchangeResult> confirmMfa({required String code, required String sessionToken}) async {
    final res = await _dio.post(
      '/_allauth/app/v1/auth/mfa/authenticate',
      data: {'code': code},
      options: Options(headers: _headers(sessionToken), validateStatus: (s) => s != null && s < 500),
    );
    if (res.statusCode == 410) throw OidcSessionExpired();
    return _parse(res.data);
  }
}
```

```dart
// lib/features/login/oidc/cubit/oidc_cubit.dart
import 'package:bloc/bloc.dart';
import 'package:paperless_mobile/api/modules/oidc_api.dart';
import 'package:paperless_mobile/features/login/oidc/cubit/oidc_state.dart';
import 'package:paperless_mobile/features/login/oidc/model/oidc_provider.dart';
import 'package:paperless_mobile/features/login/oidc/service/oidc_auth_facade.dart';

export 'oidc_state.dart';

class OidcCubit extends Cubit<OidcState> {
  final OidcApi _api;
  final OidcAuthFacade _facade;
  static const redirectUrl = 'paperlessmobile://oidc-callback';
  String? _sessionToken;

  OidcCubit(this._api, this._facade) : super(const OidcInitial());

  Future<void> start(OidcProvider provider) async {
    emit(const OidcExchanging());
    try {
      final r = await _facade.authorize(provider: provider, redirectUrl: redirectUrl);
      if (r == null) { emit(const OidcCancelled()); return; }
      final ex = await _api.exchangeProviderToken(providerId: provider.id, idToken: r.idToken, accessToken: r.accessToken);
      if (ex.accessToken != null) { emit(OidcSuccess(ex.accessToken!)); return; }
      if (ex.mfaRequired && ex.sessionToken != null) {
        _sessionToken = ex.sessionToken;
        emit(OidcOtpRequired(ex.sessionToken!));
        return;
      }
      emit(const OidcError('OIDC exchange did not return a token.'));
    } on OidcSignupRequired {
      emit(const OidcError('Account is not linked. Log in via web UI once to link your SSO identity, then retry.'));
    } on OidcSessionExpired {
      emit(const OidcError('Session expired. Please retry.'));
    } catch (e) {
      emit(OidcError(e.toString()));
    }
  }

  Future<void> confirmMfa(String code) async {
    final s = _sessionToken;
    if (s == null) { emit(const OidcError('No pending session.')); return; }
    emit(const OidcExchanging());
    try {
      final ex = await _api.confirmMfa(code: code, sessionToken: s);
      if (ex.accessToken != null) { emit(OidcSuccess(ex.accessToken!)); return; }
      emit(const OidcError('Invalid code.'));
    } on OidcSessionExpired {
      emit(const OidcError('Session expired. Please retry.'));
    } catch (e) {
      emit(OidcError(e.toString()));
    }
  }
}
```

```dart
import 'package:flutter_appauth/flutter_appauth.dart';
import 'package:paperless_mobile/features/login/oidc/model/oidc_provider.dart';
import 'package:paperless_mobile/features/login/oidc/service/oidc_auth_facade.dart';

class AppAuthOidcFacade implements OidcAuthFacade {
  final FlutterAppAuth _appAuth;
  AppAuthOidcFacade([FlutterAppAuth? appAuth]) : _appAuth = appAuth ?? const FlutterAppAuth();

  @override
  Future<OidcBrowserResult?> authorize({required OidcProvider provider, required String redirectUrl}) async {
    final discoveryUrl = provider.discoveryUrl;
    final clientId = provider.clientId;
    if (discoveryUrl == null || clientId == null || discoveryUrl.isEmpty || clientId.isEmpty) {
      throw StateError('Provider ${provider.id} is missing discovery URL or client ID.');
    }
    final result = await _appAuth.authorizeAndExchangeCode(
      AuthorizationTokenRequest(
        clientId,
        redirectUrl,
        discoveryUrl: discoveryUrl,
        scopes: const ['openid', 'profile', 'email'],
      ),
    );
    if (result == null) return null;
    if (result.idToken == null) throw StateError('IdP did not return an id_token.');
    return OidcBrowserResult(idToken: result.idToken!, accessToken: result.accessToken);
  }
}
```

```dart
// in lib/api/modules/oidc_api.dart
enum OidcFlow { direct, webFallback, none }

class OidcCapability {
  final OidcFlow flow;
  final List<OidcProvider> providers;
  const OidcCapability({required this.flow, this.providers = const []});
}

final _oidcLoginAction = RegExp(r'/accounts/oidc/([A-Za-z0-9_-]+)/login/');

List<OidcProvider> parseLoginPageProviders(String html) {
  final ids = _oidcLoginAction.allMatches(html).map((m) => m.group(1)!).toSet();
  return ids.map((id) => OidcProvider(id: id, name: id[0].toUpperCase() + id.substring(1))).toList();
}

Future<OidcCapability> detectCapabilities(String serverUrl) async {
  try {
    final headless = await _headlessAvailable(serverUrl);
    final metaProviders = await _fetchProvidersAny(serverUrl);
    if (headless && metaProviders.any((p) => (p.clientId?.isNotEmpty ?? false) && (p.discoveryUrl?.isNotEmpty ?? false))) {
      return OidcCapability(flow: OidcFlow.direct, providers: metaProviders);
    }
    final pageProviders = await _fetchLoginPageProviders(serverUrl);
    if (pageProviders.isNotEmpty) {
      return OidcCapability(flow: OidcFlow.webFallback, providers: pageProviders);
    }
    return const OidcCapability(flow: OidcFlow.none);
  } catch (_) {
    return const OidcCapability(flow: OidcFlow.none);
  }
}

Future<bool> _headlessAvailable(String serverUrl) async {
  try {
    final res = await _dio.get('$serverUrl/_allauth/app/v1/config',
        options: Options(headers: {'Accept': 'application/json'}, validateStatus: (s) => s != null && s < 500));
    final ct = res.headers.value('content-type') ?? '';
    return ct.contains('application/json') && res.data is Map;
  } catch (_) {
    return false;
  }
}

Future<List<OidcProvider>> _fetchLoginPageProviders(String serverUrl) async {
  try {
    final res = await _dio.get('$serverUrl/accounts/login/',
        options: Options(validateStatus: (s) => s != null && s < 500));
    if (res.statusCode == 200 && res.data is String) {
      return parseLoginPageProviders(res.data as String);
    }
    return [];
  } catch (_) {
    return [];
  }
}
```

```dart
      ..setJavaScriptMode(JavaScriptMode.unrestricted)
      ..setNavigationDelegate(NavigationDelegate(
        onPageFinished: (url) => _maybeFinish(url),
      ))
      ..loadRequest(Uri.parse('${widget.serverUrl}/accounts/login/?next=/dashboard/'));
  }

  Future<void> _maybeFinish(String url) async {
    if (!isSsoSessionActive(url) || _busy) return;
    setState(() => _busy = true);
    try {
      final raw = await _controller.runJavaScriptReturningResult(buildGenerateTokenJs());
      final token = parseGenerateTokenResponse(raw.toString());
      if (!mounted) return;
      if (token != null) {
        Navigator.of(context).pop(token);
        return;
      }
      setState(() { _busy = false; _error = 'Could not create an API token.'; });
    } catch (_) {
      if (!mounted) return;
      setState(() { _busy = false; _error = 'Could not create an API token.'; });
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Sign in with SSO'), actions: [
        IconButton(icon: const Icon(Icons.close), onPressed: () => Navigator.of(context).pop()),
      ]),
      body: Stack(children: [
        WebViewWidget(controller: _controller),
        if (_busy) const Center(child: CircularProgressIndicator()),
        if (_error != null) Align(alignment: Alignment.bottomCenter,
            child: Padding(padding: const EdgeInsets.all(16),
                child: Text(_error!, style: TextStyle(color: Theme.of(context).colorScheme.error))),
      ]),
    );
  }
}
```

**Symptom (live, paperless.b-b.one v2.17.1):** after completing SSO in the WebView fallback, app sits on an endless spinner (`AddUserLoadingPage`).
