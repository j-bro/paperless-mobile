# paperless_api

A Dart package that provides bindings for paperless-ngx API v9.

## Features

- Automatic type generation

## Installation

Add this package to your `pubspec.yaml`:

```yaml
dependencies:
  paperless_api: ^1.0.0
```

## Prerequisites

This package requires `openapi-generator` to be installed for code generation. Install it using:

```bash
npm install @openapitools/openapi-generator-cli -g
```
